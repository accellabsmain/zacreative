Tanya Jawab

Pertanyaan yang Sering Diajukan

Segala hal yang perlu Anda ketahui mengenai spesifikasi cetak, hak cipta naskah, tenggat waktu, dan format serah terima file.

Untuk naskah novel standar atau non-fiksi sekitar 100 - 200 halaman, pengerjaan biasanya berkisar antara 4 hingga 7 hari kerja sejak naskah final diterima. Untuk proyek mendesak (express), silakan sampaikan di awal agar kami dapat mengalokasikan slot kerja lembur khusus.
Setiap paket sudah mencakup hingga 3 putaran revisi minor. Revisi minor mencakup koreksi tipografi/typo, pergeseran letak gambar, atau penggantian teks singkat. Perubahan menyeluruh terhadap konsep gaya desain (setelah sampel halaman awal disepakati) dapat dikenakan penyesuaian biaya tambahan.
Anda akan menerima file PDF High-Resolution Siap Cetak (dengan tanda potong / bleed standar percetakan), PDF Digital ringan untuk pembaca layar / ebook, serta file presentasi (.PPTX / .KEY) jika memesan kategori slide. File master (.INDD) tersedia pada paket Tier Gold atau sebagai add-on.
