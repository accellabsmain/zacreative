Berapa lama estimasi waktu pengerjaan proyek? +
Waktu pengerjaan bergantung pada kompleksitas serta skala proyek. Untuk presentasi standar biasanya membutuhkan 3–7 hari kerja, sedangkan layout buku komprehensif berkisar antara 2–4 minggu.
Berapa batas revisi yang diberikan untuk setiap layanan? +
Secara umum paket kami mencakup 2 hingga 3 kali revisi minor setelah approval konsep awal. Perubahan konsep secara menyeluruh akan disesuaikan kembali melalui adendum kerja.
Format file apa saja yang akan diterima klien? +
Klien akan menerima file master editable (misalnya PDF high-res siap cetak, PPTX/Keynote interaktif, serta file vector/aset grafis PNG/SVG beresolusi tinggi).
